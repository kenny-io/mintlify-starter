Resources are the core building blocks of your projects in Google. Use these endpoints to programmatically list, create, retrieve, update, and delete resources in any project your API key has access to. All requests must include a valid `Authorization` header — see the [Authentication](/api/authentication) guide if you need to create or manage API keys.

## GET /v1/resources

Retrieve a paginated list of resources across your workspace. Filter by status or scope results to a specific project using the query parameters below.

**Request**

<ParamField query="page" type="integer" default="1">
  The page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  The number of resources to return per page. Maximum is `100`.
</ParamField>

<ParamField query="status" type="string">
  Filter resources by status. Accepted values: `active`, `archived`, `draft`, `completed`.
</ParamField>

<ParamField query="project_id" type="string">
  Scope results to a specific project by its unique ID.
</ParamField>

**Response**

<ResponseField name="data" type="array">
  An array of resource objects matching the query.
  <Expandable title="Resource object">
    <ResponseField name="id" type="string">
      The unique identifier for the resource.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name of the resource.
    </ResponseField>
    <ResponseField name="description" type="string">
      A human-readable description of the resource.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      The ID of the project this resource belongs to.
    </ResponseField>
    <ResponseField name="status" type="string">
      The current status of the resource: `active`, `archived`, `draft`, or `completed`.
    </ResponseField>
    <ResponseField name="assignee_id" type="string">
      The ID of the user assigned to this resource.
    </ResponseField>
    <ResponseField name="due_date" type="string">
      The due date in ISO 8601 format (`YYYY-MM-DD`).
    </ResponseField>
    <ResponseField name="created_at" type="string">
      The UTC timestamp when the resource was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      The UTC timestamp when the resource was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata for the response.
  <Expandable title="Meta object">
    <ResponseField name="total" type="integer">
      Total number of resources matching the query.
    </ResponseField>
    <ResponseField name="page" type="integer">
      The current page number.
    </ResponseField>
    <ResponseField name="per_page" type="integer">
      The number of results returned per page.
    </ResponseField>
    <ResponseField name="total_pages" type="integer">
      The total number of pages available.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>
```bash curl
curl -X GET "https://api.google.com/v1/resources?status=active&project_id=proj_9k2mXp&page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript JavaScript
const response = await fetch(
  "https://api.google.com/v1/resources?status=active&project_id=proj_9k2mXp&page=1&per_page=20",
  {
    method: "GET",
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
      Accept: "application/json",
    },
  }
);
const data = await response.json();
```

```python Python
import requests

response = requests.get(
    "https://api.google.com/v1/resources",
    params={"status": "active", "project_id": "proj_9k2mXp", "page": 1, "per_page": 20},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
data = response.json()
```
</CodeGroup>

## POST /v1/resources

Create a new resource inside a project. You must supply at minimum a `name` and a `project_id`. All other fields are optional at creation time.

**Request Body**

<ParamField body="name" type="string" required>
  The display name of the resource. Maximum 255 characters.
</ParamField>

<ParamField body="description" type="string">
  An optional human-readable description. Maximum 2,000 characters.
</ParamField>

<ParamField body="project_id" type="string" required>
  The ID of the project to create this resource in.
</ParamField>

<ParamField body="status" type="string" default="draft">
  The initial status of the resource. Accepted values: `active`, `archived`, `draft`, `completed`.
</ParamField>

<ParamField body="assignee_id" type="string">
  The ID of the workspace member to assign this resource to.
</ParamField>

<ParamField body="due_date" type="string">
  The due date in ISO 8601 format (`YYYY-MM-DD`).
</ParamField>

**Response**

<ResponseField name="data" type="object">
  The newly created resource object.
  <Expandable title="Resource object">
    <ResponseField name="id" type="string">
      The unique identifier for the newly created resource.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name of the resource.
    </ResponseField>
    <ResponseField name="description" type="string">
      The description provided at creation.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      The ID of the project the resource belongs to.
    </ResponseField>
    <ResponseField name="status" type="string">
      The status of the resource at creation time.
    </ResponseField>
    <ResponseField name="assignee_id" type="string">
      The ID of the assigned workspace member, if provided.
    </ResponseField>
    <ResponseField name="due_date" type="string">
      The due date in ISO 8601 format, if provided.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      The UTC timestamp when the resource was created.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      The UTC timestamp when the resource was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>
```bash curl
curl -X POST "https://api.google.com/v1/resources" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Brand Style Guide",
    "description": "Official brand guidelines including colors, fonts, and usage rules.",
    "project_id": "proj_9k2mXp",
    "status": "active",
    "assignee_id": "usr_3bR8vKnP",
    "due_date": "2024-10-01"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.google.com/v1/resources", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    name: "Brand Style Guide",
    description: "Official brand guidelines including colors, fonts, and usage rules.",
    project_id: "proj_9k2mXp",
    status: "active",
    assignee_id: "usr_3bR8vKnP",
    due_date: "2024-10-01",
  }),
});
const data = await response.json();
```

```python Python
import requests

payload = {
    "name": "Brand Style Guide",
    "description": "Official brand guidelines including colors, fonts, and usage rules.",
    "project_id": "proj_9k2mXp",
    "status": "active",
    "assignee_id": "usr_3bR8vKnP",
    "due_date": "2024-10-01",
}

response = requests.post(
    "https://api.google.com/v1/resources",
    json=payload,
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
data = response.json()
```
</CodeGroup>

## PUT /v1/resources/{id}

Update an existing resource. Supply only the fields you want to change — all body fields are optional. The response returns the full updated resource object.

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique identifier of the resource to update.
</ParamField>

**Request Body**

<ParamField body="name" type="string">
  A new display name for the resource. Maximum 255 characters.
</ParamField>

<ParamField body="description" type="string">
  An updated description. Maximum 2,000 characters.
</ParamField>

<ParamField body="project_id" type="string">
  Move the resource to a different project by supplying a new project ID.
</ParamField>

<ParamField body="status" type="string">
  Update the resource status. Accepted values: `active`, `archived`, `draft`, `completed`.
</ParamField>

<ParamField body="assignee_id" type="string">
  Reassign the resource to a different workspace member.
</ParamField>

<ParamField body="due_date" type="string">
  Update the due date in ISO 8601 format (`YYYY-MM-DD`).
</ParamField>

**Response**

<ResponseField name="data" type="object">
  The full updated resource object.
  <Expandable title="Resource object">
    <ResponseField name="id" type="string">
      The unique identifier for the resource.
    </ResponseField>
    <ResponseField name="name" type="string">
      The updated display name.
    </ResponseField>
    <ResponseField name="description" type="string">
      The updated description.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      The project ID the resource now belongs to.
    </ResponseField>
    <ResponseField name="status" type="string">
      The updated status.
    </ResponseField>
    <ResponseField name="assignee_id" type="string">
      The ID of the currently assigned workspace member.
    </ResponseField>
    <ResponseField name="due_date" type="string">
      The updated due date in ISO 8601 format.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      The UTC timestamp when the resource was originally created.
    </ResponseField>
    <ResponseField name="updated_at" type="string">
      The UTC timestamp reflecting the most recent update.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>
```bash curl
curl -X PUT "https://api.google.com/v1/resources/res_8hY5pMnR" \
  -H "Authorization: Bearer YOUR_API_KEY" \
```

## DELETE /v1/resources/{id}

Permanently delete a resource by its ID. This action is irreversible. On success, the API returns a `204 No Content` response with an empty body.

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique identifier of the resource to delete.
</ParamField>

<CodeGroup>
```bash curl
curl -X DELETE "https://api.google.com/v1/resources/res_8hY5pMnR" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const response = await fetch(
  "https://api.google.com/v1/resources/res_8hY5pMnR",
  {
    method: "DELETE",
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
    },
  }
);
// 204 No Content — no response body
```

```python Python
import requests

response = requests.delete(
    "https://api.google.com/v1/resources/res_8hY5pMnR",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
# 204 No Content — no response body
```
</CodeGroup>

## Error Responses

All resources endpoints return standard error envelopes. The most common errors are listed below.

### 401 Unauthorized

The `Authorization` header is missing or the API key is invalid.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "A valid Bearer token is required. Include an Authorization header with your API key.",
    "status": 401
  }
}
```

### 403 Forbidden

The API key does not have the `write` scope required for this operation.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "FORBIDDEN",
    "message": "This action requires the 'write' scope. The provided API key only has 'read' access.",
    "status": 403
  }
}
```

### 404 Not Found

No resource exists with the provided ID in your workspace.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "No resource with that ID exists in your workspace.",
    "status": 404
  }
}
```

### 429 Too Many Requests

You have exceeded your plan's rate limit. Check the `Retry-After` header and wait before retrying. See the [Rate Limits](/api/rate-limits) guide for details.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "You have exceeded the rate limit for your plan. Retry after 38 seconds.",
    "status": 429,
    "retry_after": 38
  }
}
```

### 500 Internal Server Error

An unexpected error occurred on Google's side. Retry with exponential backoff and contact support if the issue persists.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "An unexpected error occurred. Please try again or contact support.",
    "status": 500
  }
}
```
