Webhooks let your application react to events in Google in real time, without polling the API. When a subscribed event occurs — such as a resource being created or a user being removed — Google sends an HTTP `POST` request to the URL you register, containing a signed JSON payload describing the event. Use the endpoints below to register, list, and remove webhook subscriptions.

## Webhook Events

Google emits the following events that you can subscribe to when registering a webhook:

| Event | Description |
|---|---|
| `resource.created` | Fires when a new resource is created in any project. |
| `resource.updated` | Fires when an existing resource's fields are modified. |
| `resource.deleted` | Fires when a resource is permanently deleted. |
| `user.invited` | Fires when a new member is invited to the workspace. |
| `user.removed` | Fires when a member is removed from the workspace. |

## POST /v1/webhooks

Register a new webhook endpoint. Provide the URL Google should send event payloads to, the list of events you want to subscribe to, and a secret for signature verification. Store the `secret` securely — you'll use it to validate every incoming payload.

**Request Body**

<ParamField body="url" type="string" required>
  The publicly accessible HTTPS URL that Google should `POST` event payloads to. HTTP URLs are not accepted.
</ParamField>

<ParamField body="events" type="array" required>
  An array of event names to subscribe to. Accepted values: `resource.created`, `resource.updated`, `resource.deleted`, `user.invited`, `user.removed`. Pass `["*"]` to subscribe to all events.
</ParamField>

<ParamField body="secret" type="string" required>
  A secret string used to generate the HMAC-SHA256 signature sent with every delivery. Use a cryptographically random value of at least 32 characters.
</ParamField>

**Response**

<ResponseField name="id" type="string">
  The unique identifier for the registered webhook.
</ResponseField>

<ResponseField name="url" type="string">
  The endpoint URL Google delivers events to.
</ResponseField>

<ResponseField name="events" type="array">
  The list of event names this webhook is subscribed to.
</ResponseField>

<ResponseField name="status" type="string">
  The current status of the webhook. Returns `active` on successful registration.
</ResponseField>

<ResponseField name="created_at" type="string">
  The UTC timestamp when the webhook was registered.
</ResponseField>

<CodeGroup>
```bash curl
curl -X POST "https://api.google.com/v1/webhooks" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://yourapp.example.com/webhooks/google",
    "events": ["resource.created", "resource.updated", "user.invited"],
    "secret": "wh_sec_a8Kp2mXqL9rVnT5yZdE3cJ7bW"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.google.com/v1/webhooks", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    url: "https://yourapp.example.com/webhooks/google",
    events: ["resource.created", "resource.updated", "user.invited"],
    secret: "wh_sec_a8Kp2mXqL9rVnT5yZdE3cJ7bW",
  }),
});
const data = await response.json();
```

```python Python

    "url": "https://yourapp.example.com/webhooks/google",

    "https://api.google.com/v1/webhooks",
    json=payload,
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)

```

## DELETE /v1/webhooks/{id}

Unregister a webhook endpoint. Google immediately stops delivering events to the associated URL. This action is permanent — you must re-register the webhook if you want to resume delivery. On success, the API returns a `204 No Content` response with an empty body.

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique identifier of the webhook to remove.
</ParamField>

<CodeGroup>
```bash curl
curl -X DELETE "https://api.google.com/v1/webhooks/wh_7nF3kBpX" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const response = await fetch(
  "https://api.google.com/v1/webhooks/wh_7nF3kBpX",
  {
    method: "DELETE",
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
    },
  }
);
// 204 No Content — no response body
```

```python Python
import requests

response = requests.delete(
    "https://api.google.com/v1/webhooks/wh_7nF3kBpX",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
# 204 No Content — no response body
```
</CodeGroup>

## Webhook Payload Structure

Every event Google delivers to your endpoint follows the same JSON envelope. The `data` object's contents vary depending on the event type but always represent the full state of the affected resource or user at the time of the event.

<ResponseField name="event" type="string">
  The name of the event that triggered this delivery, e.g. `resource.created`.
</ResponseField>

<ResponseField name="timestamp" type="string">
  The UTC timestamp in ISO 8601 format indicating when the event occurred.
</ResponseField>

<ResponseField name="webhook_id" type="string">
  The ID of the webhook subscription that matched this event.
</ResponseField>

<ResponseField name="data" type="object">
  The full object snapshot associated with the event.
  <Expandable title="Data object (resource.created example)">
    <ResponseField name="id" type="string">
      The unique identifier of the affected resource.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name of the resource.
    </ResponseField>
    <ResponseField name="project_id" type="string">
      The project the resource belongs to.
    </ResponseField>
    <ResponseField name="status" type="string">
      The resource's current status.
    </ResponseField>
    <ResponseField name="assignee_id" type="string">
      The ID of the assigned workspace member, if any.
    </ResponseField>
    <ResponseField name="created_at" type="string">
      The UTC timestamp when the resource was created.
    </ResponseField>
  </Expandable>
</ResponseField>

**Sample Payload**

```json

}
```

## Signature Verification

Google signs every webhook delivery with an HMAC-SHA256 signature using the `secret` you provided at registration. The signature is included in the `X-Google-Signature` request header as a hex digest. Always verify this signature before processing any payload to ensure the request originated from Google and has not been tampered with.

<Warning>
  Never process a webhook payload without first validating the `X-Google-Signature` header. Skipping this check exposes your endpoint to spoofed or malicious requests that could trigger unintended actions in your application.
</Warning>

To verify the signature, compute an HMAC-SHA256 digest of the raw request body using your `secret`, then compare it to the value in the header using a constant-time comparison to prevent timing attacks.

<CodeGroup>
```javascript JavaScript (Node.js)
const crypto = require("crypto");

function verifyGoogleSignature(rawBody, signatureHeader, secret) {
  const expectedSignature = crypto
    .createHmac("sha256", secret)
    .update(rawBody, "utf8")
    .digest("hex");

  const trusted = Buffer.from(expectedSignature, "hex");
  const received = Buffer.from(signatureHeader, "hex");

  if (trusted.length !== received.length) {
    return false;
  }

  return crypto.timingSafeEqual(trusted, received);
}

// Express.js example
app.post("/webhooks/google", express.raw({ type: "application/json" }), (req, res) => {
  const signature = req.headers["x-google-signature"];
  const secret = process.env.GOOGLE_WEBHOOK_SECRET;

  if (!verifyGoogleSignature(req.body, signature, secret)) {
    return res.status(401).json({ error: "Invalid signature" });
  }

  const event = JSON.parse(req.body);
  console.log("Verified event:", event.event);

  // Process the event here
  res.status(200).json({ received: true });
});
```

```python Python
import hmac
import hashlib
import os
from flask import Flask, request, jsonify

app = Flask(__name__)

def verify_google_signature(raw_body: bytes, signature_header: str, secret: str) -> bool:
    expected = hmac.new(
        secret.encode("utf-8"),
        raw_body,
        hashlib.sha256
    ).hexdigest()
    return hmac.compare_digest(expected, signature_header)

@app.route("/webhooks/google", methods=["POST"])
def handle_webhook():
    signature = request.headers.get("X-Google-Signature", "")
    secret = os.environ["GOOGLE_WEBHOOK_SECRET"]

    if not verify_google_signature(request.get_data(), signature, secret):
        return jsonify({"error": "Invalid signature"}), 401

    event = request.get_json()
    print(f"Verified event: {event['event']}")

    # Process the event here
    return jsonify({"received": True}), 200
```
</CodeGroup>

## Retries and Delivery Failures

Google considers a delivery successful when your endpoint returns any `2xx` HTTP status code within 10 seconds. If your endpoint is unavailable, times out, or returns a non-`2xx` status, Google automatically retries the delivery.

<Tip>
  Google retries failed webhook deliveries up to **5 times** using exponential backoff, with delays of approximately 1, 5, 25, 125, and 625 minutes between attempts. Design your endpoint to be idempotent — use the `webhook_id` and `timestamp` fields in the payload to detect and safely ignore duplicate deliveries.
</Tip>

If all 5 retry attempts fail, Google marks the webhook as `disabled` and stops further delivery attempts. Re-enable the webhook by deleting it and registering a new subscription once your endpoint is stable.
