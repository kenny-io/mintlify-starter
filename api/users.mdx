The Users API lets you manage who has access to your Google workspace. Use these endpoints to list current members, look up individual user profiles, and invite new collaborators via email. All write operations — such as inviting a new user — require a key with the `write` scope issued to an Admin or Owner account.

<Note>
  Only workspace members with the **Admin** or **Owner** role can invite new users. Attempts to perform these actions with a `member` or `viewer` token will return a `403 Forbidden` error.
</Note>

## GET /v1/users

Retrieve a paginated list of all members in your workspace. Optionally filter by role to narrow the results.

**Request**

<ParamField query="role" type="string">
  Filter members by role. Accepted values: `owner`, `admin`, `member`, `viewer`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  The page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  The number of members to return per page. Maximum is `100`.
</ParamField>

**Response**

<ResponseField name="data" type="array">
  An array of workspace member objects.
  <Expandable title="User object">
    <ResponseField name="id" type="string">
      The unique identifier for the user.
    </ResponseField>
    <ResponseField name="name" type="string">
      The user's full name.
    </ResponseField>
    <ResponseField name="email" type="string">
      The user's email address.
    </ResponseField>
    <ResponseField name="role" type="string">
      The user's workspace role: `owner`, `admin`, `member`, or `viewer`.
    </ResponseField>
    <ResponseField name="avatar_url" type="string">
      A URL pointing to the user's profile avatar image.
    </ResponseField>
    <ResponseField name="joined_at" type="string">
      The UTC timestamp when the user joined the workspace.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata for the response.
  <Expandable title="Meta object">
    <ResponseField name="total" type="integer">
      Total number of workspace members matching the query.
    </ResponseField>
    <ResponseField name="page" type="integer">
      The current page number.
    </ResponseField>
    <ResponseField name="per_page" type="integer">
      The number of results returned per page.
    </ResponseField>
    <ResponseField name="total_pages" type="integer">
      The total number of pages available.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>
```bash curl
curl -X GET "https://api.google.com/v1/users?role=admin&page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Accept: application/json"
```

```javascript JavaScript
const response = await fetch(
  "https://api.google.com/v1/users?role=admin&page=1&per_page=20",
  {
    method: "GET",
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
      Accept: "application/json",
    },
  }
);
const data = await response.json();
```

```python Python
import requests

response = requests.get(
    "https://api.google.com/v1/users",
    params={"role": "admin", "page": 1, "per_page": 20},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
data = response.json()
```
</CodeGroup>

## POST /v1/users

Invite a new user to your workspace by email. Google sends an invitation email to the address you specify. The invited user appears in the members list with a `pending` status until they accept.

**Request Body**

<ParamField body="email" type="string" required>
  The email address of the person you want to invite. Must be a valid email format.
</ParamField>

<ParamField body="role" type="string" required>
  The workspace role to assign to the invited user. Accepted values: `admin`, `member`, `viewer`.
</ParamField>

**Response**

<ResponseField name="data" type="object">
  The newly created invitation object.
  <Expandable title="Invitation object">
    <ResponseField name="id" type="string">
      The unique identifier for the newly created user record.
    </ResponseField>
    <ResponseField name="email" type="string">
      The email address the invitation was sent to.
    </ResponseField>
    <ResponseField name="role" type="string">
      The role assigned to the invited user.
    </ResponseField>
    <ResponseField name="status" type="string">
      The invitation status. Returns `pending` until the user accepts the invitation.
    </ResponseField>
    <ResponseField name="invited_at" type="string">
      The UTC timestamp when the invitation was sent.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>
```bash curl
curl -X POST "https://api.google.com/v1/users" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "elena.torres@example.com",
    "role": "member"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.google.com/v1/users", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    email: "elena.torres@example.com",
    role: "member",
  }),
});
const data = await response.json();
```

```python Python
import requests

payload = {
    "email": "elena.torres@example.com",
    "role": "member",
}

response = requests.post(
    "https://api.google.com/v1/users",
    json=payload,
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
data = response.json()
```
</CodeGroup>

**Sample Response**

```json
{
  "data": {
    "id": "usr_9eW4zCsT",
    "email": "elena.torres@example.com",
    "role": "member",
    "status": "pending",
    "invited_at": "2024-08-05T11:00:00Z"
  },
  "meta": null,
  "error": null
}
```

<ParamField path="id" type="string" required>
  The unique identifier of the user to retrieve.
</ParamField>

**Response**

<ResponseField name="data" type="object">
  The full user profile object.
  <Expandable title="User object">
    <ResponseField name="id" type="string">
      The unique identifier for the user.
    </ResponseField>

      The user's full name.
    </ResponseField>
    <ResponseField name="email" type="string">
      The user's email address.
    </ResponseField>

      The user's current workspace role: `owner`, `admin`, `member`, or `viewer`.

## Error Responses

All users endpoints return standard error envelopes. The most common errors are listed below.

### 401 Unauthorized

The `Authorization` header is missing or the API key is invalid.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "A valid Bearer token is required. Include an Authorization header with your API key.",
    "status": 401
  }
}
```

### 403 Forbidden

The API key does not have sufficient scope or role permissions for this operation.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "FORBIDDEN",
    "message": "This action requires the 'write' scope and an Admin or Owner role.",
    "status": 403
  }
}
```

### 404 Not Found

No user exists with the provided ID in your workspace.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "USER_NOT_FOUND",
    "message": "No user with that ID exists in your workspace.",
    "status": 404
  }
}
```

### 429 Too Many Requests

You have exceeded your plan's rate limit. Check the `Retry-After` header and wait before retrying. See the [Rate Limits](/api/rate-limits) guide for details.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "RATE_LIMIT_EXCEEDED",
    "message": "You have exceeded the rate limit for your plan. Retry after 38 seconds.",
    "status": 429,
    "retry_after": 38
  }
}
```

### 500 Internal Server Error

An unexpected error occurred on Google's side. Retry with exponential backoff and contact support if the issue persists.

```json
{
  "data": null,
  "meta": null,
  "error": {
    "code": "INTERNAL_SERVER_ERROR",
    "message": "An unexpected error occurred. Please try again or contact support.",
    "status": 500
  }
}
```
