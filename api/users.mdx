The Users API gives you full control over who has access to your Google workspace. Use these endpoints to list current members, look up individual profiles, invite new collaborators via email, change a member's role, or remove someone from the workspace entirely. Role-based access applies to all write operations — see the note below for details.

<Note>
  Only workspace members with the **Admin** or **Owner** role can invite new users or remove existing members. Attempts to perform these actions with a `member` or `viewer` token will return a `403 Forbidden` error.
</Note>

## GET /v1/users

Retrieve a paginated list of all members in your workspace. Optionally filter by role to narrow the results.

**Request**

<ParamField query="role" type="string">
  Filter members by role. Accepted values: `owner`, `admin`, `member`, `viewer`.
</ParamField>

<ParamField query="page" type="integer" default="1">
  The page number to retrieve. Defaults to `1`.
</ParamField>

<ParamField query="per_page" type="integer" default="20">
  The number of members to return per page. Maximum is `100`.
</ParamField>

**Response**

<ResponseField name="data" type="array">
  An array of workspace member objects.
  <Expandable title="User object">
    <ResponseField name="id" type="string">
      The unique identifier for the user.
    </ResponseField>
    <ResponseField name="name" type="string">
      The user's full name.
    </ResponseField>
    <ResponseField name="email" type="string">
      The user's email address.
    </ResponseField>
    <ResponseField name="role" type="string">
      The user's workspace role: `owner`, `admin`, `member`, or `viewer`.
    </ResponseField>
    <ResponseField name="avatar_url" type="string">
      A URL pointing to the user's profile avatar image.
    </ResponseField>
    <ResponseField name="joined_at" type="string">
      The UTC timestamp when the user joined the workspace.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="meta" type="object">
  Pagination metadata for the response.
  <Expandable title="Meta object">
    <ResponseField name="total" type="integer">
      Total number of workspace members matching the query.
    </ResponseField>
    <ResponseField name="page" type="integer">
      The current page number.
    </ResponseField>
    <ResponseField name="per_page" type="integer">
      The number of results returned per page.
    </ResponseField>
    <ResponseField name="total_pages" type="integer">
      The total number of pages available.
    </ResponseField>
  </Expandable>
</ResponseField>

<CodeGroup>
```bash curl
curl -X GET "https://api.google.com/v1/users?role=admin&page=1&per_page=20" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```javascript JavaScript
const response = await fetch(
  "https://api.google.com/v1/users?role=admin&page=1&per_page=20",
  {
    method: "GET",
    headers: {
      Authorization: "Bearer YOUR_API_KEY",
      "Content-Type": "application/json",
    },
  }
);
const data = await response.json();
```

```python Python
import requests

response = requests.get(
    "https://api.google.com/v1/users",
    params={"role": "admin", "page": 1, "per_page": 20},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
data = response.json()
```
</CodeGroup>

## POST /v1/users

Invite a new user to your workspace by email. Google sends an invitation email to the address you specify. The invited user appears in the members list with a `pending` status until they accept.

**Request Body**

<ParamField body="email" type="string" required>
  The email address of the person you want to invite. Must be a valid email format.
</ParamField>

<ParamField body="role" type="string" required>
  The workspace role to assign to the invited user. Accepted values: `admin`, `member`, `viewer`.
</ParamField>

**Response**

<ResponseField name="id" type="string">
  The unique identifier for the newly created user record.
</ResponseField>

<ResponseField name="email" type="string">
  The email address the invitation was sent to.
</ResponseField>

<ResponseField name="role" type="string">
  The role assigned to the invited user.
</ResponseField>

<ResponseField name="status" type="string">
  The invitation status. Returns `pending` until the user accepts the invitation.
</ResponseField>

<ResponseField name="invited_at" type="string">
  The UTC timestamp when the invitation was sent.
</ResponseField>

<CodeGroup>
```bash curl
curl -X POST "https://api.google.com/v1/users" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "elena.Torres@example.com",
    "role": "member"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.google.com/v1/users", {
  method: "POST",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    email: "elena.torres@example.com",
    role: "member",
  }),
});
const data = await response.json();
```

```python Python
import requests

payload = {
    "email": "elena.torres@example.com",
    "role": "member",
}

response = requests.post(
    "https://api.google.com/v1/users",
    json=payload,
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
data = response.json()
```
</CodeGroup>

**Sample Response**

```json
{
  "id": "usr_9eW4zCsT",
  "email": "elena.torres@example.com",
  "role": "member",
  "status": "pending",
  "invited_at": "2024-08-05T11:00:00Z"
}
```

</ResponseField>

## PUT /v1/users/{id}

Update a workspace member's role. Use this endpoint to promote a `member` to `admin`, downgrade an `admin` to `viewer`, or any other role change your permissions allow. You cannot change the role of the workspace `owner` through this endpoint.

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique identifier of the user whose role you want to update.
</ParamField>

**Request Body**

<ParamField body="role" type="string" required>
  The new role to assign. Accepted values: `admin`, `member`, `viewer`.
</ParamField>

**Response**

<ResponseField name="id" type="string">
  The unique identifier for the user.
</ResponseField>

<ResponseField name="name" type="string">
  The user's full name.
</ResponseField>

<ResponseField name="email" type="string">
  The user's email address.
</ResponseField>

<ResponseField name="role" type="string">
  The updated workspace role.
</ResponseField>

<ResponseField name="updated_at" type="string">
  The UTC timestamp reflecting when the role was changed.
</ResponseField>

<CodeGroup>
```bash curl
curl -X PUT "https://api.google.com/v1/users/usr_9eW4zCsT" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "role": "admin"
  }'
```

```javascript JavaScript
const response = await fetch("https://api.google.com/v1/users/usr_9eW4zCsT", {
  method: "PUT",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ role: "admin" }),
});
const data = await response.json();
```

```python Python
import requests

response = requests.put(
    "https://api.google.com/v1/users/usr_9eW4zCsT",
    json={"role": "admin"},
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
data = response.json()
```
</CodeGroup>

## DELETE /v1/users/{id}

Remove a member from your workspace. The user immediately loses access to all workspace resources. This action does not delete the user's account — it only revokes their membership. On success, the API returns a `204 No Content` response with an empty body.

**Path Parameters**

<ParamField path="id" type="string" required>
  The unique identifier of the workspace member to remove.
</ParamField>

<CodeGroup>
```bash curl
curl -X DELETE "https://api.google.com/v1/users/usr_9eW4zCsT" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const response = await fetch("https://api.google.com/v1/users/usr_9eW4zCsT", {
  method: "DELETE",
  headers: {
    Authorization: "Bearer YOUR_API_KEY",
  },
});
// 204 No Content — no response body
```

```python Python
import requests

response = requests.delete(
    "https://api.google.com/v1/users/usr_9eW4zCsT",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
)
# 204 No Content — no response body
```
</CodeGroup>
